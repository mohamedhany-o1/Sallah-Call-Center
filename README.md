# Sallah Call Center Performance Dashboard
A Power BI dashboard analyzing call center performance by project, month and agent, built on three months of call data (Feb, Mar, Apr)
## Dashboard Preview
<img width="2476" height="1370" alt="Screenshot 2026-11-24 115758" src="https://github.com/user-attachments/assets/883c8aa7-15c0-428d-bfdd-389325eb33c1" />

## Key Results
- Handling Calls Ratio: 98.7%
- Service Level: 91.1%
- Abandonment Rate: 1.3%
- Average Speed of Answer (ASA): 9.22

## Key features
- Performance breakdown by project month and agnt
- Drillthrough page to investigate abandoned calls by agent


## Tools
Power BI, DAX
